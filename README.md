# @dre44/nestjs-kit

Utilities for [NestJS](https://nestjs.com) with [Fastify](https://fastify.dev).

## Barrels

Import from `@dre44/nestjs-kit/<barrel>`. Detailed usage lives in each barrel's README.

- [`connectrpc`](./src/connectrpc) - ConnectRPC servers and clients
- [`grpc-js`](./src/grpc-js) - gRPC servers and clients
- [`interactive`](./src/interactive) - Interactive console
- [`multipart`](./src/multipart/README.md) - Multipart upload decorators
- [`rabbitmq`](./src/rabbitmq) - RabbitMQ servers and clients
- [`rpc`](./src/rpc) - RPC utilities
- [`upload`](./src/upload/README.md) - Raw streaming uploads
- [`ws`](./src/ws) - WebSocket utilities
- [`zod`](./src/zod) - Zod validation utilities
